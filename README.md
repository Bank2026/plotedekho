# PloteDekho.com - Real Estate & Property Marketplace

A responsive real estate platform built with vanilla HTML, CSS, and JavaScript.

## Features
- **Admin Dashboard**: Direct form to submit real-time property listings.
- **Dynamic Property Filtering**: Filter by Area (Urban/Rural) and Type (Housing, Commercial, etc.).
- **Direct Contact Integrations**: WhatsApp click-to-chat and one-click calling via mobile.
- **Authentication Modals**: Built-in interactive Log In and Sign Up popups.
